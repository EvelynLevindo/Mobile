# App de Registro de Ponto (Armazenamento Local)

Aplicativo mobile em Flutter para registro de ponto de funcionários com restrição de raio de geolocalização e biometria. Esta versão **não utiliza Firebase**, utilizando `sqflite` (SQLite) e `shared_preferences` para armazenamento totalmente offline.

## Requisitos
- SDK do Flutter (v3.0.0 ou superior)
- Emulador ou Dispositivo Físico Android/iOS.

## Instalação
1. Clone o repositório ou copie a estrutura de arquivos.
2. Baixe as dependências executando no terminal:
